Welcome to **Space Voyage**, a web application crafted for interstellar expeditions, planetary exploration, and relativistic space travel simulations. Designed with rich cosmic aesthetics, fluid 60 FPS HTML5 Canvas systems, procedural Web Audio acoustics, and real-time spacecraft cockpit telemetry.

---

## 🌟 Key Features

### 🌌 1. Interactive 3D Starfield & Hyperspace Warp Engine
- **Depth-projected 3D Starfield**: Over 850 stars with realistic depth calculations, colors, and twinkling dynamics.
- **Mouse Gravity Parallax**: Starfield dynamically tilts and pans in response to cursor position.
- **Hyperspace Jump Sequence**: Accelerates stars into relativistic light streaks with full-screen cinematic warp tunnel effects.
- **Atmospheric Shooting Meteors**: Intermittent meteoric streaks with particle glow trails.

### 🪐 2. Procedural 3D Planetary Sphere Renderer
- **Interactive Drag-to-Rotate**: Click and drag the celestial sphere to rotate any planet on horizontal and vertical axes.
- **Dynamic Atmospheric Halos**: Radial gradient glow effects customized per planet type (terrestrial, icy, gas giant).
- **Surface Continents & Cloud Swirls**: Procedurally generated surface features and rotating planetary cloud bands.
- **Rings & Planetary Systems**: Translucent tilted ring systems rendered for gas giants like Titan and Saturn.

### 🎛️ 3. Spacecraft Cockpit Telemetry HUD
- **Antimatter Reactor Core**: Live output fluctuations (4.82 GW) with an animated reactor core visualizer.
- **Circular Deflector Shield Gauge**: Dynamic SVG circular gauge monitoring shield deflection integrity.
- **Relativistic Velocity Readout**: Real-time velocity gauge showing speed as a fraction of light speed ($0.924c$) and km/s.
- **Life Support & Gravity Bars**: Real-time oxygen mix and artificial gravity sensors.

### 🎫 4. Interstellar Reservation Engine & Boarding Pass
- **Relativistic Lorentz Dilation**: Calculates time dilation using Einstein's special relativity ($\gamma = 1 / \sqrt{1 - v^2/c^2}$).
- **Vessel & Cabin Configuration**: Choose between Cryo-Stasis Pods, Orbital Suites, and Zero-G Penthouses.
- **Holographic Boarding Pass**: Live flight badge with flight codes, route lines, stardates, and simulated barcode verification.

### 🔊 5. Web Audio API Ambient Synthesizer
- **Zero-Dependency Sound**: Built entirely with procedural oscillators, filters, and gain nodes.
- **Binaural Deep Space Drone**: Calming sub-bass hum with slow, breathing LFO low-pass filter sweeps.
- **Cybernetic Sound Effects**: Interactive UI beeps, sonar radar pings, and hyperdrive acceleration sound effects.

### 📡 6. Astronomical Phenomena Tracker & Expedition Logs
- **Real-Time Countdown Timers**: Active countdown clocks tracking upcoming meteor swarms, solar radiation flares, and planetary eclipses.
- **Historical Expedition Logs**: Chronological timeline of humanity's expansion across the Sol system and into deep space.

## 🏗️ Technology Stack

- **Core**: Semantic HTML5 (optimized for SEO, OpenGraph, accessibility)
- **Styling**: Vanilla CSS3 (Custom Properties, Glassmorphism, Neon Glow Tokens, CSS Grid, Flexbox)
- **Visuals**: HTML5 Canvas 2D / 3D Projection Engine
- **Sound**: Web Audio API (Sine/Triangle/Sawtooth Oscillators, Biquad Filters, LFOs)
- **Typography**: Google Fonts (`Orbitron`, `Space Grotesk`, `Outfit`, `Inter`)
- **Version Control**: Git & GitHub with modular, atomic commits

## 🚀 Quick Start / Local Preview

No heavy node package managers or compilers required! The application runs natively in any modern web browser.

### Option 1: Live Server or Any Static HTTP Server
```bash
# Using Python built-in server
python -m http.server 8000

# Or using Node http-server / npx serve
npx serve .
```
Then navigate to `http://localhost:8000` in your web browser.

### Option 2: Direct File Open
Simply double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
